# EffectMaster – Web Editor
Web editor for EffectMaster. Allows the user to create, delete, edit and play shows from a website.

Uses React and TypeScript.

Please view the [EffectMaster repo](https://github.com/Ym64/EffectMaster) and [Relay Server repo](https://github.com/Ym64/EffectMaster-relay) for more information about the connection.
